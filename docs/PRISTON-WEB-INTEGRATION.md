## Area and NPC asset packs (12/11/2026)
- Environment: https://acesso.gbtechnology.com.br/priston-classic/ (Classic Lab, not legacy VelluM).
- Original startup pack gzip optimization remains active (84.5 MB -> 44.7 MB), original kept for fallback.
- Compressed region packs generated by ops/build-classic-area-packs.py:
  * Ricarten: 367 files, 15.64 MB compressed.
  * NPC core: 174 files, 9.78 MB compressed (subset of NPC models/textures; does not cover every NPC).
  * Initial forest: 809 files, 10.67 MB compressed (subset of forest assets).
- The page starts ops/priston-prewarm-worker.js in a separate browser worker after reaching Running; no blocking of game startup. The worker decompresses PTPB+gzip and stores individual files in browser Cache Storage pt-data-1 with X-PT-Version manifest hashes.
- Browser automation: all 1,350 region/NPC assets confirmed in cache and Running maintained; approximately 21 sec after test start for background completion. Later reload logs Pack reused for all three and no full pack download.
- Service worker ops/priston-classic-sw.js also predicts nearby resources when an NPC/map asset is requested, with strict per-group byte limits and 4 background workers.
- Installer ops/integrate-priston-web.ps1 regenerates packs only when source manifest SHA256 changed; retains binary web resources.
- This is a partial preload, not proof that every NPC or map loads instantly; actual click-to-open gameplay has not been measured comprehensively.
