FREEston Tale - REVISAO 21

INSTALAR
1. Feche a versao antiga e extraia o ZIP em outra pasta.
2. Copie .local-data da pasta antiga para preservar personagens e contas.
3. Pode copiar .original-cache para reaproveitar os downloads.
4. Abra INICIAR.bat (rede local) ou INICIAR_INTERNET.bat (Internet).
Python 3.10+ e navegador com WebGL. Internet no primeiro download.
O iniciador de Internet suporta Windows 64 bits.

LOJA E COINS
/loja, F9 ou Loja premium abre o Item Shop nativo. Compre com coins e ative
com o botao direito no item da bolsa. Premiums ativos ficam a direita.
/coins 1000 adiciona para voce (admin). /coins bielbt 1000 adiciona para a ID bielbt.
O ID e o login da conta. Os coins valem para todas as classes e ficam no servidor.

LINK
INICIAR_INTERNET.bat abre http://127.0.0.1:19065/painel.
Entre como admin e clique Copiar link. O endereco tambem fica em LINK_DO_JOGO.txt.
O painel informa se o link esta pendente, verificado ou offline.
Falha de DNS e verificada novamente automaticamente.
Mantenha PC e tunel ligados; fechar o tunel encerra o acesso.
URL permanente depende de dominio e tunel nomeado configurado pelo operador.
O painel permite criar contas de jogador e trocar a senha inicial.

ATUALIZAR
ATUALIZAR.bat abre um seletor de ZIP. Pacotes compativeis atualizam a interface,
guardam backup em .updates e preservam os dados sem desligar servidor/tunel.
No jogo, clique Salvar e atualizar. A pagina recarrega com progresso salvo.
Mudancas no backend Python exigem reiniciar/instalar o pacote completo.
